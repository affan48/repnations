# repnations

REPNATIONS Premium US Activewear & Performance Gymwear Storefront.

## Overview
A headless e-commerce storefront engineered for **REPNATIONS** (`https://repnations.com`), integrated with the live Shopify catalog and designed for the US fitness apparel market.

## Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide Icons + Google Fonts (Barlow Condensed & Inter)
- **State & Commerce:** React Context API + LocalStorage + Shopify Cart Permalinks
- **Routing:** React Router DOM v6

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
